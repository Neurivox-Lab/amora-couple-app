## 🚀 Key Features

### 1. 🏠 Home ("Our Day")
- **Days in Love Counter**: Live calculation of total days together (`428 Days in Love`).
- **Synchronized Daily Question**: Daily romantic prompt (e.g., *"What is one small thing your partner did that melted your heart?"*). Answers stay locked until both partners submit, then reveal with floating heart celebrations.
- **Couple Streak & Flame System**: Tracks daily shared moments with active streak protection.
- **Live Mood & Virtual Touch**: Instant mood status (🥰 In Love, 😊 Happy, 🌿 Chill, 😴 Tired, 🥺 Need Hugs, 😤 Stressed). Tap to send rhythmic haptic vibrations and a 3D heart shower to your partner's phone.

### 2. 🎮 Play (Games Hub)
- **Would You Rather?**: Categorized into *Romantic & Future* 🏡 and *Late Night & Spicy* 🔥 with match percentage detection.
- **Who Is More Likely To?**: Synchronous card flipping to vote on each other in real time.
- **Truth or Dare (Couple Edition)**: Intimate confessions and romantic dares with spicy levels.
- **Couples Decision Spinner (Wheel of Fortune)**: Physics-based rotating wheel to resolve *"What should we eat?"*, *"Who picks the movie?"*, or *"Tonight's date idea"*.

### 3. 📅 Explore & Dates
- **Cupid AI Date Planner**: Customized itineraries generated by mood, time (2 hrs, half day, full day), and budget (₹0-500, ₹500-1500, ₹1500+).
- **Mystery Scratch-off Cards**: Interactive scratch-to-reveal secret weekend dates.
- **Shared Bucket List**: Categorized (Travel, Food, Experiences, Romance, Goals) with progress trackers.
- **7-Day Intimacy Challenges**: Daily bite-sized romantic tasks.

### 4. 📸 Memories & Scrapbook
- **Polaroid Digital Scrapbook**: Photo gallery with captions, location tags, date stamps, and favorite pins.
- **"Our Story" Interactive Timeline**: Milestone ladder from *First Text* &rarr; *First Date* &rarr; *Anniversaries* &rarr; *Today*.
- **"Open When..." Sealed Letters**: Time-capsule letters locked until specific conditions (e.g., *"Open when you miss me"*, *"Open on our anniversary"*).

### 5. ❤️ Us & Cupid AI
- **Love Languages Compatibility Radar**: Visual breakdown across Quality Time, Physical Touch, Words of Affirmation, Acts of Service, and Receiving Gifts.
- **Cupid AI Relationship Coach**: AI-powered date planner, love letter polisher, conflict de-escalation coach, and surprise generator.
- **Demo Mode Switcher**: Instant 1-tap switch between Partner 1 (Srinija) and Partner 2 to test real-time couple synchronization on a single device or browser.

## 🛠️ Technology Stack

| Layer | Technology | Details |
|---|---|---|
| **Mobile Client** | React Native (Expo SDK 52) + TypeScript | React Navigation, Reanimated, Expo Haptics, Expo Linear Gradient, Lucide Icons |
| **Backend API** | Spring Boot 3.3.4 (Java 21 LTS) | Spring Security (Stateless JWT), Spring Data JPA, Spring WebSocket (STOMP) |
| **Database** | PostgreSQL (Production) / H2 (In-memory dev) | Hibernate ORM, auto-seeding with 100+ questions and demo couple (`AM-8X7K`) |
| **AI Companion** | Google Gemini API (Cupid AI) | Date planning, letter drafting, empathy coaching |

## 💻 How to Run

### 1. Start the Spring Boot Backend

```bash
cd backend
mvn spring-boot:run
```
*API runs at `http://localhost:8080` (H2 Console at `http://localhost:8080/h2-console`).*

### 2. Start the Mobile Client

```bash
cd mobile
npm start
# Or launch directly in web browser:
npm run web
# Or launch on Android device / emulator:
npm run android
```

## 📦 Play Store Build

The app is pre-configured with Android package identifier `com.amora.coupleapp`, adaptive icons, camera/vibration permissions, and responsive layout.

To build an Android APK / AAB for Google Play Store:
```bash
cd mobile
npx eas build -p android --profile production
```
